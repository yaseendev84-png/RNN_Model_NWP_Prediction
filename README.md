# 🔮 Shakespeare's Hamlet Next Word Predictor

A deep learning web application built with **Streamlit** and **Python** to forecast the next word in a sentence using language patterns learned from William Shakespeare's *The Tragedy of Hamlet, Prince of Denmark*.

---

## 📌 Features

* **Direct Word Prediction:** Enter any custom phrase or sentence to receive an instant next-word prediction along with its confidence probability score.
* **Text Completion:** Displays the full completed sentence combining your original input with the predicted word.
* **Interactive Novel Viewer:** View and toggle the complete text corpus of *Hamlet* directly within the sidebar.
* **Model KPIs & Metrics:** Track key performance indicators such as Perplexity, Top-1/Top-5 Accuracy, and Loss progression across training epochs.
* **Real-World Use Cases:** Built-in guidance explaining practical applications of next-word generation (e.g., smart keyboards, search engine autocomplete).

---

## 🛠️ Tech Stack & Requirements

* **Python:** 3.8+
* **Streamlit:** Web application framework
* **Pandas:** Data handling and structure
* **NumPy:** Numerical calculations
* **Altair:** Data visualization
